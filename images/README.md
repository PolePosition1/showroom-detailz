# Image Folders

Place images in these folders:

- `images/hero/` — Hero background only (do not replace h9DfB.jpg)
- `images/gallery/` — Gallery page images
- `images/before-after/` — Before & after shots
- `images/home/` — Homepage supporting images (mobile setup, interiors, etc.)
- `images/logo/` — Logo files

The site will reference these paths once images are uploaded.
