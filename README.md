## Deploy for Live Demo
This is a static site. Deploy to Vercel for the easiest live review URL:

1. Go to [vercel.com](https://vercel.com) and import this GitHub repo.
2. Framework preset: Other (static).
3. Deploy. You'll get a live URL in under a minute.
